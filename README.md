# BSGC 업무 대장

업체별 처리 절차, 진행 중 업무와 기한, 완료 기록과 특이 처리 사례를 한곳에서 관리하는 회사 내부용 대시보드입니다.

화면(`index.html`)은 GitHub Pages에서 열고, 업무 데이터(`data.enc.json`)는 회사 Google Drive의 유틸 폴더에 보관합니다.

| 파일 | 위치 | 용도 |
|---|---|---|
| `index.html` | GitHub 저장소 | 대시보드 화면 전체 |
| `README.md` | GitHub 저장소 | 이 안내문 |
| `data.enc.json` | Google Drive 유틸 폴더 | 암호화된 업무 데이터. **GitHub에는 올리지 않습니다.** |
| `gmail-to-ledger.gs` | Google Apps Script | Gmail 라벨 연동 (선택). 저장소에 둘 필요 없습니다. |

## 보안 구조

- GitHub 저장소에는 데이터가 없는 화면 코드만 있습니다. 저장소가 공개되어 있어도 업무 내용은 드러나지 않습니다.
- 업무 데이터는 브라우저 안에서 비밀번호로 암호화(AES-256-GCM)된 뒤 파일로 저장됩니다. 비밀번호는 어디에도 저장되지 않습니다.
- 비밀번호는 단어 네다섯 개를 이어 붙인 16자 이상으로 정하세요. 잊으면 복구할 수 없습니다.
- 주민등록번호, 계좌번호, 개인 연락처 같은 개인정보는 기록에 넣지 마세요. 원본 서류는 Drive에 두고 링크만 남기세요.
- Gmail 연동 주소와 토큰도 암호화된 데이터 안에 저장됩니다.

## 처음 설치

1. GitHub 저장소(`bluestripe_workspace`)에 `index.html`과 `README.md`를 올립니다 (Add file → Upload files → Commit changes).
2. Settings → Pages에서 Source를 "Deploy from a branch", Branch를 `main` / `(root)`로 두고 Save. 1~2분 뒤 `https://<아이디>.github.io/bluestripe_workspace/` 로 열립니다.
3. 사이트에 접속해 비밀번호를 정하고 "새 대장 만들기"를 누릅니다.
4. 오른쪽 위 "암호화 파일 받기"로 받은 `data.enc.json`을 Drive 유틸 폴더에 저장합니다.

**권장 설정 두 가지**

- **PC용 Google Drive 설치.** 유틸 폴더가 탐색기의 일반 폴더처럼 보여서, 저장하고 여는 일이 로컬 파일처럼 간단해집니다.
- **크롬 다운로드 위치 확인 켜기.** 크롬 설정 → 다운로드 → "다운로드 전에 각 파일의 저장 위치 확인"을 켜면, 파일을 받을 때마다 유틸 폴더를 골라 바로 덮어쓸 수 있습니다.

## 매일 쓰는 방법

**평소 쓰는 PC에서**

1. 사이트를 열고 비밀번호를 넣습니다. 입력한 내용은 그 PC 브라우저에 암호화되어 자동 저장되므로, 파일을 고르지 않아도 바로 열립니다.
2. 업무를 기록합니다.
3. 하루를 마칠 때 상단에 "Drive에 저장할 변경이 있습니다"가 보이면 "암호화 파일 받기" → 유틸 폴더의 `data.enc.json`에 덮어씁니다. 저장하고 나면 "최신 파일을 받아 두었습니다"로 바뀝니다.

**다른 PC에서**

1. 사이트를 열면 첫 화면에 "Drive에서 대장 파일 열기"가 있습니다. 유틸 폴더의 `data.enc.json`을 고르고 비밀번호를 넣습니다.
2. 이미 그 PC에서 쓴 적이 있다면 비밀번호 화면 아래 "다른 대장 파일 열기"로 Drive 파일을 고르세요. 브라우저에 남은 내용과 Drive 파일 중 더 최근 것이 열립니다.
3. 작업을 마치면 똑같이 "암호화 파일 받기"로 Drive에 덮어씁니다.

**주의할 점**

- **두 PC에서 동시에 입력하지 마세요.** 나중에 덮어쓴 파일만 남습니다. PC를 옮길 때는 앞 PC에서 Drive에 저장 → 다음 PC에서 Drive 파일 열기 순서를 지키세요.
- **파일 이름은 늘 `data.enc.json`으로 유지하세요.** `data.enc (1).json`처럼 번호가 붙어 저장됐다면 기존 파일을 지우고 이름을 맞춥니다. 같은 이름으로 덮어쓰면 Drive가 이전 버전을 자동 보관하므로, 잘못 저장했을 때 파일 오른쪽 클릭 → "버전 관리"에서 되돌릴 수 있습니다.
- **"새 대장 만들기"는 처음 한 번만 누르세요.** 다른 PC에서 실수로 새 대장을 만들어도 Drive 파일은 그대로 있으니, "다른 대장 파일 열기"로 Drive 파일을 다시 열면 됩니다.

## 업무 흐름

**새 건을 받으면** 홈의 "업무 시작"을 누르거나, 업체 화면의 절차 카드에서 "이 절차로 시작"을 누릅니다. 절차의 단계와 필요 서류가 체크리스트로 들어갑니다. 입력창 아래에는 그 업체의 같은 업무 이력, 다른 업체의 같은 유형 특이 사례, 고른 품목의 수입요건이 함께 보입니다.

**진행하면서** 기록 카드의 "단계 n/m"을 펼쳐 항목을 체크합니다. 체크한 날짜가 함께 남습니다.

**기한이 생기면** 기록 수정 창의 "기한"에서 종류와 기준일을 넣습니다. 홈의 "챙길 기한"에 날짜순으로 뜨고, 7일 이내는 빨간 테두리, 지난 기한은 빨간 바탕으로 표시됩니다. 처리했으면 체크박스를 눌러 목록에서 뺍니다.

**끝나면** "완료 처리"를 누릅니다. 진행 요약을 비워 두면 체크리스트 진행 내역으로 자동 작성됩니다. 일반 절차와 다르게 처리했다면 "일반 절차와 다르게 처리함"을 체크하고 특이 처리 내용을 적습니다.

**특이 사례가 쌓이면** 카드의 "절차에 반영"으로 다음에 적용할 점을 해당 절차의 주의사항에 덧붙입니다. 날짜와 함께 남아 어느 사례에서 나온 내용인지 알 수 있습니다.

## 기한 자동 계산

| 기한 종류 | 기준일 | 계산 |
|---|---|---|
| FTA 사후적용 신청 | 수입신고 수리일 | 1년 |
| 세액 보정신청 | 신고납부일 | 6개월 |
| 경정청구 | 최초 신고납부일 | 5년 |
| 수출물품 적재기한 | 수출신고 수리일 | 30일 |
| 관세환급 신청 | 수출 이행일 | 2년 |
| 직접 입력 | — | 검사 일정, 업체 약속 등 날짜를 직접 지정 |

계산은 초일을 넣지 않는 일반 규정 기준의 참고값입니다. 말일이 공휴일이면 다음 날로 미뤄지는 점, 개별 협정이나 사안별 예외는 반영하지 않으니 중요한 기한은 직접 확인하세요. 규칙은 `index.html`의 `DL_RULES`에서 고치거나 늘릴 수 있습니다.

## 품목·요건

업체 화면 위쪽의 "품목·요건"에 자주 들어오는 품목의 HS 코드, 세율과 적용 협정, 수입요건, 요건 기관을 정리합니다. 기록에서 품목을 고르면 요건이 참고 패널에 뜹니다. 검색창에 HS 코드를 점이나 하이픈 없이 입력해도 찾아집니다.

## 월간 리포트

왼쪽 "월간 리포트"에서 월별 완료 건수, 업체별·유형별 건수, 특이 처리 비율, 대행 수수료 합계를 봅니다. 막대를 누르면 그 달로 이동합니다. "청구용 CSV 받기"는 엑셀에서 바로 열리는 형식으로 그 달 완료 기록을 내려받습니다. 수수료는 기록의 "대행 수수료" 칸에 넣은 값만 집계됩니다.

## Gmail 라벨 연동 (선택)

처리가 끝난 메일 스레드에 Gmail에서 `업무완료` 라벨을 붙이면, 대장의 "메일 초안"에서 기록 초안으로 가져올 수 있습니다. 기록을 만들거나 "무시"를 누르면 그 스레드의 라벨이 `대장반영`으로 바뀝니다.

1. Gmail 계정으로 [script.google.com](https://script.google.com)에서 새 프로젝트를 만들고, `gmail-to-ledger.gs` 내용을 붙여 넣어 저장합니다.
2. 위쪽 함수 선택에서 `setup`을 고르고 실행합니다. 권한 요청을 승인하면 실행 기록에 토큰이 표시됩니다. 라벨 두 개도 이때 만들어집니다.
3. 배포 → 새 배포 → 유형 "웹 앱" → 다음 사용자로 실행 "나", 액세스 권한 "모든 사용자" → 배포. 표시되는 웹 앱 URL(`…/exec`)을 복사합니다.
4. 대장의 "데이터" 메뉴 → Gmail 연동에 웹 앱 주소와 토큰을 넣고 저장합니다.
5. "메일 초안" → "메일 불러오기".

알아 둘 점:

- 웹 앱은 토큰이 맞을 때만 응답하고, `업무완료` 라벨이 붙은 메일의 제목, 보낸 사람, 날짜, 본문 앞 600자만 보냅니다. 토큰이 새었다고 생각되면 `resetToken`을 실행하고 대장의 토큰을 바꾸세요.
- 업체 정보의 "메일·Drive 검색어"에 업체 메일 도메인(예: `@abc.co.kr`)을 넣어 두면 초안이 그 업체로 자동 연결됩니다. 하나비로에서 포워딩할 때 보낸 사람이 바뀌는 방식이라면, 도메인 대신 메일 제목에 늘 들어가는 업체명을 검색어로 넣으세요.
- 제목이나 본문에 수입신고번호 형식(`12345-26-1234567U`)이 있으면 참조번호에 자동으로 들어갑니다.
- 스크립트를 고친 뒤에는 배포 → 배포 관리 → 수정 → 새 버전으로 다시 배포해야 반영됩니다.

**Claude 요약 (선택, 기본은 꺼짐)**: 스크립트의 `USE_CLAUDE`를 `true`로 바꾸고 `saveClaudeKey`로 Anthropic API 키를 저장하면 스레드 전체를 5줄로 요약해 초안에 넣습니다. 이 경우 고객사 메일 본문이 Anthropic API로 전송되므로, 비밀유지 의무와 고객 동의 여부를 먼저 판단하신 뒤 켜세요.

## 백업과 설정

- Drive가 `data.enc.json`의 이전 버전을 자동 보관하므로 그것이 1차 백업입니다.
- 비밀번호를 잊는 경우에 대비하려면 "데이터" 메뉴 → "평문 JSON 받기"로 받은 파일을 가끔 개인 폴더에 보관하세요. 평문이므로 공유 폴더나 GitHub에는 두지 마세요.
- 비밀번호를 바꾸면 새 파일을 받아 Drive에 저장해야 합니다. Drive의 이전 버전 파일은 예전 비밀번호로 열립니다.
- 업무 유형 목록은 "데이터" 메뉴에서 바꿉니다.
- Gmail 계정이 여러 개라 다른 계정이 열리면 `index.html`의 `GMAIL_ACCOUNT = 0` 숫자를 바꾸세요.
- `/` 키를 누르면 검색창으로 바로 이동합니다.
